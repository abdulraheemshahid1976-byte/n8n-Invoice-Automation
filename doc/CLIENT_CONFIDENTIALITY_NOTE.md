# Client Confidentiality Note

This repository is intended as a portfolio presentation of an invoice automation workflow.

Important guidance before publishing publicly:

- review screenshots and demo video for any visible client names, email addresses, invoice identifiers, or internal folder names
- replace or blur sensitive content if the repository will be made public
- keep the video private or share it on request only if it contains client-facing operational data

The safest public version of this project is one that emphasizes:

- workflow architecture
- automation logic
- tool integrations
- redacted demo artifacts

If needed, create a private/internal version and a separate public portfolio version.
